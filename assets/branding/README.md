# Sybil artwork

The Sybil mark and account glyphs in this directory are original geometric
artwork created for the Sybil beta. The forest, paper, and lime palette follows
the Sybil UI tokens. `profile_glyphs.svg` is the source sheet for the 15 PNGs
under `assets/profile_pictures/`; their filenames and `pfp-01` through
`pfp-15` identifiers remain stable so existing wallet data keeps resolving.

The Android and Linux launcher PNGs are rasterized from `sybil_mark.svg`, and
the Android adaptive foreground is rasterized from `sybil_mark_foreground.svg`.
The app keeps the upstream Vizor asset licenses and attribution in
`assets/legal/NOTICE`; this directory does not replace or remove those notices.
