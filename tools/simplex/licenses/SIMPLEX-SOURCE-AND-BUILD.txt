SimpleX Chat v7.0.2 corresponding-source and build-input record
================================================================

This record accompanies the AGPL-3.0 text in
SimpleX-Chat-v7.0.2-LICENSE. It describes the source package prepared for a
Sybil beta distribution. It does not change the wallet's repository-level
Apache License 2.0 or replace any upstream component notice.

The package preserves exact source and build-input hashes for review. It does
not claim a bit-for-bit rebuild of the upstream or Sybil binaries.

Exact runtime Haskell source coverage
-------------------------------------

The inspected Linux runtime contains 157 mapped Haskell runtime identities:
145 Hackage archives, the ten pinned Git inputs above, and GHC 9.6.3 source
for the bundled core/RTS libraries. The complete package-level mapping is in
`manifest/HASKELL-RUNTIME-SOURCES.json`; hashes, sizes, URLs, and license
file evidence are in `manifest/HACKAGE-PINS.tsv`.

Two shared-library stems need an explicit mapping because they are not ordinary
package names in the runtime filename parser:

* `libHSrts-1.0.2_thr-...-ghc9.6.3.so` maps to
  `dependencies/ghc/ghc-9.6.3-src.tar.xz` as the GHC RTS source.
* `libHSattoparsec-0.14.4-l-attoparsec-internal-...-ghc9.6.3.so` maps to
  `dependencies/hackage/attoparsec-0.14.4.tar.gz`; it is the internal library
  built from that same Hackage package, not a separate source package.
