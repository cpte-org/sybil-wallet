# SimpleX legal and corresponding-source inputs

`SimpleX-Chat-v7.0.2-LICENSE` is the verbatim AGPL-3.0 text from the pinned
SimpleX Chat source revision. Its SHA-256 is
`8486a10c4393cee1c25392769ddd3b2d6c242d6ec7928e1414efff7dfb2f07ef`.

`SIMPLEX-SOURCE-AND-BUILD.txt` records the v7.0.2 source and binary hashes,
Git dependencies, observed Haskell runtime sources, native inputs and build
pins. The public beta attaches `sybil-simplex-source-v7.0.2.tar.gz` at the
release URL recorded there, alongside the binaries.

The package retains upstream copyrights and dependency notices. The wallet,
JNI adapter and process wrapper source are available at the wallet release
tag. Source and version coverage do not imply a bit-for-bit reproduction of
the official upstream native binaries.
