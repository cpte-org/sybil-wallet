# Sybil Wallet v1.0.0-beta.1

This is the first Sybil public beta for Zcash mainnet on Linux and Android.
It is an experimental self-custody release for testing the wallet, contact,
and Public Zcash names flows with disposable funds and backups.

## What's New

- Linux x64 and Android ARM64 beta builds for Zcash mainnet.
- Create or import wallets, receive and send shielded ZEC, shield transparent
  funds, manage multiple accounts, and use the existing wallet recovery flow.
- Manual and QR contact exchange in People, with optional SimpleX delivery on
  Linux and Android.
- Public Zcash names management against the deployed Base mainnet registry.
- A ZEC-funded mainnet name registration has been validated through the
  reviewed wallet flow.

## Improvements

- Sybil uses its own public beta defaults and product presentation while
  preserving upstream compatibility identifiers and notices where required.
- Android is distributed as a separate Sybil application with application ID
  `cash.sybil.wallet` and a new release signing identity.

## Installation

- Linux x64: extract the release archive into an empty directory and launch
  `./vizor`. Keep the sibling `lib/` and `data/` directories beside it.
  Requires a recent Linux distribution with glibc 2.38+, libstdc++ providing
  GLIBCXX_3.4.31, GTK 3 and a working Secret Service keyring. This build was
  validated on the development Linux host, not every distribution.
- Android ARM64: sideload the APK with the Android package installer or
  `adb install sybil-beta-mainnet-arm64.apk`. It installs beside
  Vizor because it uses a separate application ID.

## Notes

- Install the Android beta beside Vizor if desired. It does not automatically
  migrate Vizor wallet data; back up the recovery material before testing and
  import it explicitly into the Sybil app when appropriate.
- SimpleX delivery is foreground-only on Linux and Android and does not use
  Tor in this beta. Portable contact backup covers linked contacts and their
  relationship keys only; it does not include manually saved addresses, notes,
  pins, or the SimpleX database.
- Mobile background delivery and funds-return handling are deferred.
- The release has not received an independent security audit. Use small test
  amounts and review every transaction before authorizing it.

## Authenticity and source

Verify the archive or APK against `SHA256SUMS` attached to this release.
The Android signing certificate SHA-256 is:

```text
9D:3F:CD:37:BF:27:CE:74:55:1E:BB:FF:39:E2:16:36:AA:55:1D:6F:C1:BD:2C:C6:F9:28:C0:5B:37:2F:1E:C9
```

Keep your recovery phrase and encrypted contact backup separately. The Android
release signing key is not a wallet recovery key.

The release tag contains the wallet and integration source. The attached
`sybil-simplex-source-v7.0.2.tar.gz` supplies the pinned SimpleX component,
dependency sources, notices and build inputs. Third-party notices are also
available inside the app through its license viewer.
